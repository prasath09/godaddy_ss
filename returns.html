Return / Exchange Items

Refund value uses the actual item value after item discount and a proportional share of the original bill discount. An item already returned cannot be returned again.

Exchange Selected Item

For exchange, scan an exact replacement physical-piece barcode or generated price barcode. If the new item costs more, the system shows the amount to collect; if lower, it shows the refund.

Cancel Entire Bill

Cancellation does not delete the invoice. It marks the bill as CANCELLED, restores eligible stock, and preserves the bill number and history.
